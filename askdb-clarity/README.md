# AskDB frontend

React 19 · TanStack Start/Router/Query · Tailwind 4 · Recharts.

```bash
cp .env.example .env     # VITE_API_URL=http://localhost:8000
npm install
npm run dev
npm run typecheck
```

## Structure

```
src/
  routes/            file-based routes: _app.tsx (shell) + _app/{index,ask,sql,schema,tables,connections}.tsx
  state/workspace.tsx   active connection, Ask AI conversation, hand-off drafts
  lib/api.ts         typed backend client (the only place that calls fetch)
  lib/format.ts      number/time/cell formatting
  components/
    layout/          app shell, connection switcher, RequireConnection guard
    query/           results table, SQL block, chart, export menu, verdict/guardrail UI
    connect/         connection form (demo · upload · credentials)
    common/ui.tsx    PageHeader, Panel, EmptyState, ErrorNotice, Pill…
    ui/              button, dropdown-menu, input, skeleton
```

Server data is owned by TanStack Query; `WorkspaceProvider` only holds what must survive navigation.
`routeTree.gen.ts` is generated by the router plugin on `npm run dev`/`build`.
